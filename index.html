قوائمي المحفوظة (M3U)

احفظ رابط قائمة M3U من مزوّد مرخّص مرة وحدة، وتظهر دائمًا في قائمة المصادر بتبويب القنوات.

فتح رابط مرة وحدة

ضع رابط قائمة M3U أو رابط بث مباشر (.m3u8 / .mp4) لتشغيله فورًا بدون حفظ.

مفتاح يوتيوب الشخصي (اختياري)

الأفلام تظهر للجميع بدون مفتاح. المفتاح الشخصي يضيف البحث المباشر في كل يوتيوب:

  1. افتح صفحة YouTube Data API v3 وسجّل دخولك بحساب Google.
  2. أنشئ مشروعًا جديدًا (أي اسم)، ثم اضغط Enable.
  3. من Credentials اضغط Create credentials ← API key وانسخ المفتاح.
  4. الصقه هنا واضغط حفظ. يُحفظ على جهازك فقط.

أفلام كاملة (أطول من 20 دقيقة) يسمح أصحابها بعرضها خارج يوتيوب.

شغّل أفلامك المحفوظة على الجهاز (MP4 / WebM / MKV حسب دعم المتصفح).
